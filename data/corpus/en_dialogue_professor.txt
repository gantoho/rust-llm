B: Let's walk through it step by step. Can you show me what you have so far?
A: Sure. Here's my code:
```python
def reverse(head):
    prev = None
    current = head
    while current:
        next_node = current.next
        current.next = prev
        prev = current
        current = next_node
    return prev
```
B: Actually, this looks correct! What's happening when you run it?
A: It's reversing the list, but when I try to print it, I only get the first element.
B: How are you printing the list?
A: Like this:
```python
def print_list(head):
    current = head
    while current:
        print(current.val)
        current = current.next
```
B: I see the issue. After reversing, are you updating your head pointer?
A: Oh! I think I see. The head still points to the old first node, which is now the last node.
B: Exactly! The reverse function returns the new head, but if you don't capture it, you're still using the old head.
A: So I should do:
```python
head = reverse(head)
print_list(head)
```
B: That's right! The reverse function returns the new head of the reversed list. You need to assign it back to your head variable.
A: That makes sense now. What about the time complexity?
B: The time complexity is O(n) because we visit each node exactly once. The space complexity is O(1) because we only use a constant amount of extra space.
A: What if the list is empty or has only one node?
B: Good question! Your code handles both cases correctly. If the list is empty, head is None, and the while loop doesn't execute. If there's one node, prev becomes the head after one iteration.
A: I see. What about the recursive approach?
B: The recursive approach is elegant but uses O(n) space due to the call stack. Here's how it looks:
```python
def reverse_recursive(head):
    if not head or not head.next:
        return head
    new_head = reverse_recursive(head.next)
    head.next.next = head
    head.next = None
    return new_head
```
A: That's beautiful but harder to understand.
B: Yes, the iterative approach is usually preferred in practice because it's more memory efficient and easier to debug.
