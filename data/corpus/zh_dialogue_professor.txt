A: 教授，我对作业有个问题。
B: 当然！你在做哪道题？
A: 第三章的第5题，关于链表的。
B: 啊，是的。具体哪里让你困惑？
A: 我不确定如何实现反转函数。我理解概念，但代码不工作。
B: 让我们一步步来。能给我看看你写的代码吗？
A: 好的。这是我的代码：
```python
def reverse(head):
    prev = None
    current = head
    while current:
        next_node = current.next
        current.next = prev
        prev = current
        current = next_node
    return prev
```
B: 实际上，这看起来是正确的！运行时发生了什么？
A: 它反转了链表，但当我尝试打印时，只得到第一个元素。
B: 你是怎么打印链表的？
A: 这样：
```python
def print_list(head):
    current = head
    while current:
        print(current.val)
        current = current.next
```
B: 我发现问题了。反转后，你更新头指针了吗？
A: 哦！我想我明白了。头指针仍然指向原来的第一个节点，而现在它变成了最后一个节点。
B: 完全正确！reverse函数返回新的头节点，但如果你不捕获它，你仍然在使用旧的头节点。
A: 所以我应该这样做：
```python
head = reverse(head)
print_list(head)
```
B: 没错！reverse函数返回反转后链表的新头节点。你需要把它赋值回head变量。
A: 现在明白了。时间复杂度是多少？
B: 时间复杂度是O(n)，因为我们只遍历每个节点一次。空间复杂度是O(1)，因为我们只使用常量的额外空间。
A: 如果链表为空或只有一个节点呢？
B: 好问题！你的代码能正确处理这两种情况。如果链表为空，head是None，while循环不执行。如果只有一个节点，一次迭代后prev变成头节点。
A: 明白了。递归方法呢？
B: 递归方法很优雅，但由于调用栈使用O(n)空间。代码如下：
```python
def reverse_recursive(head):
    if not head or not head.next:
        return head
    new_head = reverse_recursive(head.next)
    head.next.next = head
    head.next = None
    return new_head
```
A: 很漂亮但更难理解。
B: 是的，实践中通常首选迭代方法，因为它更节省内存且更容易调试。
