# 第 26 课：梯度累积 —— 小显存也能跑大 batch

> 代码位置：[src/train.rs](src/train.rs)（训练循环中的梯度累积逻辑）
> 代码位置：[src/config.rs](src/config.rs)（`TrainConfig.accum_steps`）
>
> 配置开关：`config.json` → `train.accum_steps: 4`（1 = 不累积）

---

## 1. 本课要搞懂的问题

1. 为什么大 batch 训练效果好，但显存放不下？
2. 梯度累积是怎么用多个小 batch 模拟大 batch 的？
3. loss 为什么要除以 `accum_steps`？

---

## 2. 大 batch 的好处与困境

### 2.1 好处

- 梯度估计更准确（噪声更小）
- 训练更稳定
- GPU 利用率更高（大矩阵运算效率更高）

### 2.2 困境

显存占用 ∝ batch_size：

```
显存 ≈ 模型参数 + 优化器状态 + 激活值(batch_size * T * D * n_layer)
```

例如 LLaMA-7B 在 batch_size=32 时需要 ~40GB 显存，单卡放不下。

---

## 3. 梯度累积的原理

**核心思想**：不更新参数，累积多个小 batch 的梯度，等效于大 batch。

```
标准大 batch（batch_size=32）:
  loss = forward(x[0:32])
  loss.backward()
  optimizer.step()

梯度累积（accum_steps=4, micro_batch=8）:
  for i in 0..4:
      loss = forward(x[i*8:(i+1)*8]) / 4    # loss 除以 accum_steps
      loss.backward()                        # 梯度自动累加
  clip_grad_norm()
  optimizer.step()                           # 累积完才更新
  zero_grad()
```

### 3.1 为什么要除以 `accum_steps`？

`loss.backward()` 计算的是 `d(loss)/d(param)`。

如果累积 4 次，梯度会是 4 倍大。除以 4 保证最终梯度等于"用完整大 batch 算一次"的结果。

```
等效 loss = (loss_1 + loss_2 + loss_3 + loss_4) / 4
```

---

## 4. 实现要点

### 4.1 训练循环修改

```rust
for step in 0..steps {
    let (x, y) = sample_batch(rng);
    let logits = model.forward(&x, ...);
    let loss = cross_entropy_loss(&logits, &y);
    let scaled_loss = loss.mul_scalar(1.0 / accum_steps as f32);
    scaled_loss.backward();  // 梯度累加到现有梯度上

    if (step + 1) % accum_steps == 0 {
        clip_grad_norm(&params, grad_clip);
        optimizer.step();
        optimizer.zero_grad();
    }
}
```

### 4.2 有效 batch size

```
有效 batch_size = micro_batch_size * accum_steps
```

例如 `batch_size=8, accum_steps=4` → 有效 batch_size = 32。

### 4.3 学习率调度

学习率调度器按"每步"计数（不是每个 micro-batch），所以 `scheduler.step()` 在每次 forward 后都调用，
但 `optimizer.step()` 只在累积完成后调用。

---

## 5. 梯度累积 vs 数据并行

| | 梯度累积 | 数据并行（DDP） |
|---|---------|--------------|
| 硬件 | 单卡 | 多卡 |
| 通信 | 无 | AllReduce 梯度 |
| 速度 | 线性慢（N 步才更新一次） | 接近线性加速 |
| 映射 | 模拟大 batch | 真正的大 batch |

梯度累积是"穷人版"的大 batch 训练：不需要多卡，但训练速度会变慢（每 accum_steps 步才更新一次）。

---

## 6. 配置示例

```json
{
  "train": {
    "batch_size": 8,
    "accum_steps": 4
  }
}
```

有效 batch_size = 32，但每步只占用 batch_size=8 的显存。

---

## 7. 关键要点

- 梯度累积用多个小 batch 模拟大 batch，解决显存不足问题
- loss 除以 `accum_steps` 保证梯度等效
- 每 `accum_steps` 步才做一次 optimizer.step() + zero_grad()
- 有效 batch_size = micro_batch_size * accum_steps
- 代价：训练速度变慢（更新频率降低）
