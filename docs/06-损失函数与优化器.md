## 2. 损失函数：一杆"错得有多离谱"的秤

训练 = 让模型输出不断接近目标。怎么量化"接近"？用**损失函数** `L(pred, target)`：

- L 越大 → 错得越离谱
- 训练就是不断减小 L

两类任务对应两个损失：

| 任务 | 预测什么 | 损失函数 |
|------|----------|----------|
| 回归 | 连续数值（房价、温度）| MSE（均方误差）|
| 分类 | 属于哪个类别（猫/狗、下一个 token）| CrossEntropy（交叉熵）|

语言模型本质是"预测下一个 token 是哪一类"，所以 LLM 用的是 CrossEntropy。

## 3. MSE：均方误差（回归）

**公式**：

```
MSE = (1/N) · Σᵢ (predᵢ - targetᵢ)²
```

**对应代码**（`loss.rs`，全是一行链式调用）：

```rust
/// 均方误差：loss = mean((pred - target)²)
pub fn mse_loss(pred: &Tensor, target: &Tensor) -> Tensor {
    pred.sub(target)
        .pow(2.0)
        .sum()
        .mul_scalar(1.0 / pred.numel() as f32)
}
```

| 步骤 | 代码 | 作用 |
|------|------|------|
| 相减 | `pred.sub(target)` | 误差 eᵢ = predᵢ − targetᵢ |
| 平方 | `.pow(2.0)` | eᵢ²：消除正负抵消、放大大误差 |
| 求和 | `.sum()` | Σ eᵢ² |
| 取平均 | `.mul_scalar(1/N)` | 除以元素总数 N（`pred.numel()`）|

**为什么平方？** 正负误差不会互相抵消；大误差被放大（对离群点更敏感）。

**梯度**（不需要手写，自动微分自动算出来）：

```
∂L/∂predᵢ = 2·(predᵢ - targetᵢ) / N
```

## 4. CrossEntropy：交叉熵（分类）

分类任务里模型输出的是 **logits**（每个类别的"原始分数"），要把它变成"概率"再用交叉熵衡量。

**输入**：

- `logits`: [B, D] —— B 个样本，每个 D 个类别的分数
- `targets`: [B] —— 每个样本真实类别的下标

**数学公式**：

```
loss = -(1/B) · Σᵢ log( softmax(logitsᵢ)[targetsᵢ] )
```

对应代码分两步（`src/loss.rs:27-65`）：

```rust
pub fn cross_entropy_loss(logits: &Tensor, targets: &[usize]) -> Tensor {
    assert_eq!(logits.rank(), 2, "交叉熵的 logits 应为 [B, D]");
    let (b, d) = (logits.shape()[0], logits.shape()[1]);
    for &t in targets {
        assert!(t < d, "目标类别越界：{} >= {}", t, d);
    }

    // —— 第 1 步：log_softmax（数值稳定版，log-sum-exp 技巧）——
    let log_probs = logits.log_softmax_last_dim();

    // —— 第 2 步：gather——只取每个样本正确类别的 log 概率 ——
    let lp = log_probs.data.borrow();
    let mut gathered = vec![0.0f32; b];
    for (i, &t) in targets.iter().enumerate() {
        gathered[i] = lp[i * d + t];     // 直接按行偏移取数，省掉 one-hot 分配和整行乘法
    }
    drop(lp);

    // —— 第 3 步：取负、取均值 ——
    let mean_loss: f32 = -gathered.iter().sum::<f32>() / b as f32;
    // …… 构造标量 loss 节点；反向时只在 [i, targets[i]] 位置累加 -g/B ……
    Tensor::new(vec![mean_loss], vec![], log_probs.req())
}
```

> 早期版本按 one-hot 思路写：先构造 `[B, D]` 的 one-hot 张量再 `mul` 取正确位置。现在改成了 gather 写法（`src/loss.rs:26` 注释：避免分配 `[B, vocab_size]` 的 one-hot 矩阵）。

### 逐步拆解

**第 1 步 log_softmax**：`log_softmax_last_dim` 直接把分数变成 log 概率。

> 注：它内部用 log-sum-exp 技巧（先减最大值再 exp），既避免朴素"先 softmax 再 log"的 `log(0) = -inf`，也避免指数溢出（`src/tensor.rs:1868-1912`）。

**第 2 步 gather 取正确类别**：`gathered[i] = lp[i * d + targets[i]]`，即每个样本正确类别的 log 概率。

**第 3 步 取负 + 取均值**：

- 正确概率越高 → `-log p` 越小 → loss 越小 ✓
- 所有样本累加后除以 B（样本数）取平均

### 数值例子（2 类、2 个样本，示意）

| 样本 | logits | softmax | 正确类别 | −log p |
|------|--------|---------|----------|--------|
| 第 1 个 | [2.0, 0.5] | [0.82, 0.18] | 0 | −ln 0.82 ≈ 0.20 |
| 第 2 个 | [0.1, 1.8] | [0.15, 0.85] | 1 | −ln 0.85 ≈ 0.17 |

平均 loss ≈ (0.20 + 0.17) / 2 ≈ 0.18。如果模型对正确类别给出概率接近 1，loss 就接近 0。

> 关于梯度：softmax + 交叉熵的组合，数学上 dlogits 等于 `(p − onehot)/B`（预测概率减去 one-hot）。代码没有真的构造 one-hot 张量，而是把这个式子拆成两段手写的反向：`log_softmax_last_dim` 的反向 `g_i - s_i·Σg`（`src/tensor.rs:1920-1933`），以及 `cross_entropy_loss` 反向时只在 `[i, targets[i]]` 位置累加 `-g/B`（`src/loss.rs:54-63`）。

## 5. 梯度下降原理：沿着"最陡的下坡"走

回顾第 2 课的核心公式，对每个参数 θ：

```
θ = θ - 学习率 × ∂L/∂θ
```

- `∂L/∂θ > 0`：θ 增大 loss 也增大 → 减去它，θ 变小
- `∂L/∂θ < 0`：θ 增大 loss 减小 → 减去它，θ 变大
- 学习率（lr）控制每步迈多大：**太小**收敛慢，**太大**来回震荡甚至发散

几何直觉：loss 是参数的山坡，梯度指向"上升最快的方向"，我们每次都朝**反方向**走一小步，就像小球从山坡滚下。

```
loss
  │        .
  │      .   .
  │    .       .
  │  .           .
  └──────────────────→ θ
```

## 6. SGD：把更新规则写成代码

**随机梯度下降（SGD）**是最朴素的优化器（`src/optim.rs:28-55`）。它实现统一的 `Optimizer` trait：`step` 是**原位更新**（直接改参数自己的数据缓冲区，不新建 `Vec`），`zero_grad` 用 trait 的默认实现：

```rust
/// 优化器统一接口
pub trait Optimizer {
    fn params(&self) -> &[Tensor];
    fn step(&mut self);
    /// 清零所有参数的梯度（两种优化器共用同一实现）
    fn zero_grad(&self) {
        for p in self.params() {
            p.zero_grad();
        }
    }
}

pub struct SGD {
    lr: f32,
    params: Vec<Tensor>,
}

impl Optimizer for SGD {
    fn params(&self) -> &[Tensor] { &self.params }

    /// 更新一步：θ = θ - lr * g（原位更新，避免每次克隆整份数据）
    fn step(&mut self) {
        for p in &self.params {
            let g = p.grad.borrow();
            let mut d = p.data.borrow_mut();
            for j in 0..d.len() {
                d[j] -= self.lr * g[j];
            }
        }
    }
}
```

**公式与代码的对应**：

| 公式 | 代码 |
|------|------|
| θ（当前参数值）| `p.data.borrow_mut()`（原位修改）|
| g（梯度）| `p.grad.borrow()` |
| θ − lr·g | `d[j] -= self.lr * g[j]` |
| 写回 | 不需要——改的就是参数自己的缓冲区（旧版"先算新 `Vec` 再 `set_data` 整体替换"的写法已经去掉了）|

两个方法的**分工**：

- `step()`：必须在 `loss.backward()` 之后调用，否则梯度全是 0，参数纹丝不动；签名是 `&mut self`，所以优化器要声明成 `let mut opt = ...`
- `zero_grad()`：这里是 `trait Optimizer` 的默认实现（`src/optim.rs:21-25`），SGD / AdamW 共用。每轮更新后必须清零梯度：反向传播是 `+=` 累加（第 2 课讲过），不清零的话下一轮的梯度会叠加上一轮的旧梯度

> 顺带一提：`optim.rs` 里还有 AdamW（第 17 课讲）。它把"固定步长"换成"动量 + 自适应步长"，但接口完全一样（`step()` / `zero_grad()`），这正是统一接口的好处。

## 7. 训练循环：四步舞

一次完整的学习 = 四步（所有深度学习框架训练循环的骨架）：

```rust
// 1. 前向：算预测和损失
let logits = model.forward(&x);
let loss = cross_entropy_loss(&logits, &y_targets);
// 2. 反向：自动算出每个参数的梯度
loss.backward();
// 3. 更新：θ = θ - lr·g
opt.step();
// 4. 清零梯度：否则下一轮会累加
opt.zero_grad();
```

**顺序很重要**：`backward → step → zero_grad`，反了或漏了都会出错。

## 10. 本课总结

- **MSE**：回归任务的 `mean((pred - target)²)`
- **CrossEntropy**：log_softmax → gather 取正确类别 → 取负 → 取均值（不构造 one-hot），分类任务标配（LLM 用它）
- **SGD**：`θ = θ - lr·g`，一行代码一个循环
- **训练循环** = 前向 → 反向 → 更新 → 清零，四步缺一不可
