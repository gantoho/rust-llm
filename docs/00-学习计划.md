# 从零用 Rust 实现大语言模型 —— 学习计划

> 目标：不使用任何深度学习框架（如 tch-rs / candle / burn），仅用 Rust 标准库，
> 从零手写张量、自动微分、神经网络层、Transformer 架构，最终训练出一个能生成文本的可用 Transformer 模型。
>
> 核心理念：**每一步都亲自动手实现，每一步都配套教程文档。**
> 每节课的文档都在 `docs/` 目录下，代码在 `src/` 目录下，一一对应。
>
> **最终成果**：一个真实可用的 LLM 训练与推理框架，支持训练、评估、生成、对话、监督微调（SFT）、微调、Beam Search、GPU 加速等完整功能。

---

## 为什么从零写？

- 学习张量/自动微分/反向传播，才能真正理解 PyTorch 等框架背后的原理。
- 理解每一个数学公式如何变成一行行代码。
- 训练过程透明可控，随时可以打印中间结果检查正确性。

## 依赖策略

- **原则上零依赖**：所有张量、数学运算、自动微分、网络层全部自己写。
- 允许极少量工具库，使用时会明确说明并解释其作用（例如 `serde_json` 做配置序列化、`clap` 做命令行、`rayon` 做 CPU 并行、`tiny_http` 起 HTTP 服务、可选的 `wgpu` 做 GPU 加速）。
- 每新增一个依赖都必须有理由，不能"图省事"。

> 本阶段把模型从经典风格升级到 LLaMA/Mistral 风格。
> 每一课替换一个组件，学完后你的模型架构与现代 LLM 完全对齐。

| 课 | 主题 | 知识点 | 替换了什么 |
|----|------|--------|-----------|
| 20 | RoPE 旋转位置编码 | 把相对位置揉进 Q/K 向量（频率表按 `head_dim` 逐头重复；相邻配对 / `rotate_half` 两种配对方式；长度外推 Linear / NTK / YaRN 已落地） | 替换正弦位置编码（第 11 课） |
| 21 | RMSNorm | 去掉减均值和 β，只保留方差归一化 | 替换 LayerNorm（第 11 课） |

| 23 | GQA 分组查询注意力 | 多个 Q 头共享 K/V 头；**延伸：MLA 低秩压缩 KV Cache**（`model.kv_lora_rank`，DeepSeek-V2/V3） | 替换标准 MHA（第 10 课） |

### 阶段十二：训练进阶与低精度（第 42~50 课）

> 本阶段补上"用更少的监督、更少的比特训练模型"以及"更聪明的优化与架构微调"这几件事：
> 蒸馏把大模型的知识搬给小模型，FP8 / FP4 把数值精度一路压到 8 位、4 位浮点，WSD 换掉 cosine 的调度曲线，
> QK-Norm 钉死注意力 Q/K 的尺度，Muon 把更新矩阵正交化，mHC 把残差流拓宽成多条并用双随机矩阵约束混合，
> CSA + HCA 把长序列注意力在序列维压缩后只对少数块做稀疏打分，
> MLA 解耦 RoPE 把位置信息从压缩 latent 里摘出来，从而解锁 W_UK/W_UV 权重吸收。
> 各课都配有可运行实验与数值自检
> （梯度有限差分 / 标准码值对照 / Newton–Schulz 闭式核对 / 双随机投影不变量 / 覆盖不变式 / 吸收数值等价）。

- 第 42 课结束时，理解并用上了知识蒸馏：
  - `cargo run --release -- distill` 跑完三节：软标签熵随温度的变化、KD 梯度有限差分核对
    （最大误差 ~1e-4 量级）、「软标签 vs 硬标签」同学生同数据对照
  - 明白 `T²` 为什么不能省、为什么 teacher 与学生必须共用分词器
- 第 43 课结束时，理解 FP8 并量出它的数值代价：
  - `cargo run --release -- fp8` 跑完三节：E4M3/E5M2 标准码值对照、分块缩放的误差/开销权衡、
    权重落 FP8 后的 loss 变化
  - **清楚它的边界**：本仓库是**纯数值模拟**，不带来任何加速；真实收益来自 GPU FP8 tensor core
  - `train.fp8` 打开后每步把二维权重按 E4M3 + 每 32 元素一 scale 往返量化，梯度与优化器状态仍是 f32
- 第 44 课结束时，理解并会用 WSD 调度：
  - `train.lr_schedule = "wsd"` + `wsd_decay_frac` 后曲线呈三段式（warmup 线性上升 → 稳定段恒为 `max_lr` → 末段线性退火到 `min_lr`）
  - 明白"稳定段任意时刻都能切出退火"为什么让总步数不必前置；默认 `"cosine"` 与加 WSD 之前**逐位相同**
- 第 45 课结束时，明白 QK-Norm 解决什么问题：
  - `model.qk_norm = true` 后每个头的 `head_dim` 向量 RMS = 1（**投影之后、RoPE 之前**），对输入整体缩放不变
  - 清楚它的代价：每层多 `2 × head_dim` 参数，且会让 GPU 常驻快路失效、退回逐算子路径
- 第 46 课结束时，能用 Muon 跑通训练并且知道坑在哪：
  - `train.optimizer = "muon"` 后二维权重走 Newton–Schulz 正交化、一维参数自动回退 AdamW
  - 记住"沿用 AdamW 的学习率 Muon 会几乎不动"——每元素更新量约 `lr/√cols`，峰值学习率要放大 `√cols` 倍
  - Muon 的状态能进 checkpoint 续训（`state` / `restore_state` 往返一致）
- 第 47 课结束时，理解 mHC 并把残差流真正拓宽过：
  - `model.n_stream = 2` 后每层多了 `hc_attn` / `hc_mlp` 两组门控参数（`α` / `β` / `A`），
    模型入口把一条残差流扩成 2 条、出口用可学 `γ` 收敛回一条
  - 说得清 **双随机矩阵** 为什么能同时保证"谱范数为 1（信号不放大）"与"列和为 1（保均值）"，
    以及 Sinkhorn–Knopp 迭代为什么能当"投影算子"用还照样能反向
  - 知道两个实测踩过的坑：入口各流雷同会让首层 `α`/`A` 拿不到梯度；收敛用**均匀平均**
    会让末层 `β`/`A` 变成死参数（所以收敛权重 `γ` 必须是可学的）
  - 默认 `n_stream = 1` 不构造任何超连接参数、前向**逐位不变**
- 第 48 课结束时，理解 FP4 并把"4 位"的账算清楚：
  - `cargo run --release -- fp4` 跑完三节：E2M1 全 16 码对照、分块缩放的位宽 / 精度账本、
    f32 / FP8 / FP4 三方验证 CE 对照
  - 说得清 E2M1 为什么**既没有 Inf 码也没有 NaN 码**——`|x| > 6` 与 `NaN` 都只能饱和到 ±6.0
  - 算得清 `5 bit/元素 = 4 bit 码 + 每 32 元素摊 1 bit scale`（对 f32 6.4 倍），
    而 FP8 是 `9 bit/元素`（3.56 倍）；**别把"4 位"直接当成"省 8 倍"**
  - `train.fp4` 打开后每步把二维权重按 E2M1 + 每 32 元素一个 scale 往返量化回写，
    梯度与优化器状态仍是 f32；与 `train.fp8` 同开时以 FP4 为准
- 第 49 课结束时，理解 CSA + HCA 混合注意力并把长序列的账算清楚：
  - `cargo run --release -- csa` 跑完三节：三分支覆盖不变式、KV 字节账本、top-k 稀疏算力账本
  - 说得清三层各自管什么——局部窗口给"最近的 m 个位置"全分辨率，细压缩（CSA）给
    "已完成块"的块均值 + top-k 稀疏，粗压缩（HCA）再平均一遍给出廉价的全局覆盖
  - 记得住那条唯一的因果判据：**压缩块只有在块末位置 ≤ i 时才可见**（`B_i = floor((i+1)/m)`）；
    用"块起点 ≤ i"会让块内尚未生成的 token 漏进来，loss 会虚假变好
  - 算得清两组账：KV 字节 `2·(m + T/m)·n_kv·hd·4`（存储口径，m ≈ √T 附近最省），
    与每 query 槽位 `m + top_k + floor(T/(m·hca))`（算力口径），两者互相独立
  - 知道三层为什么能并进**一次 softmax**：各层只是把不同范围的 key 放进同一行分数，
    掩码逐行对齐后一次归一化，等价于在并集 `[0, i]` 上做注意力
  - 默认 `csa_block = 0` 时注意力仍走 `flash_attention`，前向**逐位不变**（且不新增任何参数）
- 第 50 课结束时，理解 MLA 解耦 RoPE 与权重吸收：
  - `cargo run --release -- mla` 跑完三节：增量缓存字节账本、吸收的解码算力账本、解耦约束自检
  - 说得清"把 RoPE 从 K 里摘出来单独走低维通路"为什么是吸收的**前提**——
    旋转会让 K 不再是 latent 的线性函数，而吸收恒等式 `q_nope·(c·W_UK) = (q_nope·W_UKᵀ)·c` 要求线性
  - 记得住两处 bias 的不同命运：`b_k` 是逐 head 常数、softmax 里**自动抵消**；
    `b_v` 因 `Σp = 1` 会整体平移输出、**必须补回**
  - 算得清两组账：增量缓存 `T·(r + n_head·hd_rope)·4`（对照全量 `2·T·n_head·head_dim·4`），
    与吸收后 T 项系数从 `2·n_head·r·hd_nope` 降到 `2·n_head·r`（比值趋近 `hd_nope`）
  - 知道吸收的边界：仅**无梯度推理**可用、与 QK-Norm 互斥、解耦要求 `n_kv_head ∈ {0, n_head}`
  - 默认 `mla_rope_dim = 0` 时不构造 `c_qr`/`c_kr`、不消耗随机数，前向**逐位不变**
